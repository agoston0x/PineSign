Sign in as administrator

Connect the wallet that administers this server and sign a message. Nothing is spent — the signature only proves the wallet is yours.

First run

Nobody administers this server yet. Paste the token from the server console once, to claim it for your wallet — after this you will only need the wallet.

Lost the wallet?

Sign in with the console token instead.

Choose a name

Every user of this server gets a subname under it — alice.yourname.eth — and their encryption key is published in its records.

.eth

Checked on both Sepolia and mainnet — a name owned on mainnet is one you could never carry past the testnet, so it is not offered.

Generate the server wallet

This server needs a wallet of its own. It registers the name, deploys the receipt contract, and then pays for every subname your users mint — so they never need gas or a token. The key is generated here and written only to .storage/, never to the repository.

Fund the server wallet

You need Sepolia ETH. Nothing below can happen without it. Pay from your own wallet with a package below, or send to the address in the top right by hand — faucets: sepoliafaucet.com, faucet.quicknode.com/ethereum/sepolia.

Fund from your wallet

Pick what this server should be able to do. Each package covers setup plus a number of users and transfers, with margin for gas moving.
