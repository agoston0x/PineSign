Setup token required

The server printed a setup link to its console when it started. Open that link, or paste the token here.

1 Choose a name

Every user of this server gets a subname under it — alice.yourname.eth — and their encryption key is published in its records. Pick a name you own or can register on Sepolia.

2 Generate the deployer

This server needs a wallet of its own: it deploys the receipt contract and then pays for every subname your users mint, so they never need gas or a token. The key is generated here and written only to .storage/.

3 Fund the server

This wallet pays for everything your users do not: the name, the contract, and every subname and receipt after that. Send it Sepolia ETH — the page notices when it arrives.
